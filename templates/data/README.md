# Deal harness data

Your deal memory. Plain markdown, versioned with git (the harness commits after each write).

- `memory/accounts/<account>.md`: people, decision map, signals
- `memory/deals/<account>/`: angles, scenarios, discounts, promises, probabilities, outcome, meetings/
- `memory/history/<account>.md`: past deals rebuilt from email
- `memory/followups.md`, `memory/lessons/`, `memory/edits/`
- `company/`: business model, ICP, voice, brand, rate cards, battle cards, playbook
- `config.md`: settings; `config.local.md`: settings for this machine only (not committed)
